# AGENTS.md

## Project
Personal portfolio website for selling websites and digital business services.

## Stack
- Vanilla HTML
- Vanilla CSS
- Vanilla JavaScript
- No frameworks unless explicitly requested

## Principles
- Keep code simple, clean and easy to edit manually
- Avoid unnecessary dependencies
- Fully responsive
- Accessible and keyboard-friendly
- Good SEO and performance
- Do not over-engineer

## Design
- As instructed, keep it professional and minimal
- Desktop layout follows the approved reference design
- Fixed left sidebar on desktop
- Mobile navigation replaces sidebar on smaller screens
- Dark/light theme support
- Subtle animated floating dust particles
- No inspirational quotes or motivational slogans

## Image assets
- Optimise raster images before using them on the live site.
- Prefer WebP/AVIF where appropriate.
- Do not convert photographs to SVG.
- Resize images to sensible display dimensions rather than shipping unnecessarily large originals.
- Preserve visual quality while keeping file sizes small.
- Use responsive image techniques where useful.
- Do not unnecessarily compress logos or vector artwork; use SVG for suitable vector graphics.

## Workflow
- Do not redesign existing approved sections unless asked
- Make focused changes only
- Preserve existing functionality when editing
